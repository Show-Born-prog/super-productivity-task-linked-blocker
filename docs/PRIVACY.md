# データと権限

## 保存するもの

配布版の登録ルールと一時的な連携ファイルは、ユーザーフォルダー内の `.task-linked-blocker/runtime/` に保存します。初回セットアップで、同じ`.task-linked-blocker`内の`installation.json`に補助機能の置き場所を記録します。ルールを本体のクラウド同期へ載せません。開発用の`npm run build`は従来どおり開発フォルダー内の`.local/runtime/`を使います。

解除後にタブを戻すため、元のURLをChrome拡張のメモリ内に保持します。URLをログ・ディスク・Windows補助機能へ送りません。

タスク名やメモを補助機能へ渡さず、キー入力・画面・クリップボードも取得しません。

## 必要な権限

| 権限・接続 | 用途 |
| --- | --- |
| 本体のタスク・タグ読取 | 計測中タスクのタグに合うルールを選択 |
| 本体の `nodeExecution` | ローカル設定の読み書きと補助機能の起動 |
| Chromeの `tabs` | 既存タブの禁止サイト判定と画面の切替 |
| Chromeの `declarativeNetRequest` | 禁止ドメインへの新しいページ移動を遮断 |
| Chromeの `alarms` | 状態の期限切れを確認 |
| `127.0.0.1`への接続 | 同じPCの補助機能とWebSocketで通信（ポート47821） |

`nodeExecution` は任意のプログラムも実行できる強い権限です。導入元とソースを信頼できる場合に許可してください。

通信はPC内に限定し、登録した拡張のOriginを確認します。この仕組みは、同じPCの悪意あるプログラムを隔離するものではありません。

## 外部通信と常駐処理

本プラグインから開発者への通信、アクセス解析、クラウド判定はありません。本体とChrome自身の更新・同期等の通信は、それぞれの設定に従います。

Windows補助機能は、遮断対象のある計測中だけ起動し、停止・休憩・対象なしで終了します。本体内プラグインとChrome拡張は、タスク再生を受けるため待機します。

`hosts`、Windowsサービス、タスクスケジューラー、ファイアウォール設定は変更しません。
