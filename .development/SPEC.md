# タスク連動ブロッカー — 現在の要求仕様

このファイルが現在有効な要求の唯一の正本。要求を満たしたかどうかはコードと検証結果で判断する。実装・検証状況は`CHECKPOINT.md`に記録し、この仕様と混同しない。

## 目的と連動

Windows 11上のSuper Productivityで、実際に時間を計測しているタスクの既存タグに応じて、禁止リストを自動適用する。再生で開始、停止で解除、別タスクで切替。選択中・最後に選ばれただけのタスクは根拠にしない。独自カテゴリー、独自のタスク管理・時間計測・Focus Mode・ポモドーロは作らない。

- タグIDにルールを紐づけ、タグ名の変更で対応を失わない。日常のタスク・時間・本体設定を勝手に変更しない。
- タグごとに禁止Windowsアプリと禁止サイトのドメインを追加・変更・削除できる。禁止リストを基本とし、未登録対象は許可する。サイトにはタグごとに有効化できる許可例外を設ける（2026-11-05ユーザー決定）。許可リスト以外をすべて遮断する方式にはしない。
- **複数タグは各禁止リストの合算とする（2026-11-04ユーザー決定）。** 重複は禁止対象を増やさない。タグなし・設定対象タグなしでは遮断しない。
- 計測中のタグ変更も反映する。削除済みタグを別タグとして誤適用しない。
- タスク停止、Focus Modeの休憩、接続切れ・データ期限切れ・状態不明では遮断を解除し、保護できていないことを表示する。クラッシュ後に古いルールを残さない。
- 再起動・プラグイン再読込でも計測状態を確認してから有効にする。古い状態の復元だけでは有効にしない。
- **補助プロセスは遮断対象のあるタスクを計測している間だけ起動する。** 停止・休憩・状態不明・禁止対象なしでは終了し、本体側の毎秒の状態更新も停止する。停止から再生へ自動で起動し直し、素早い切替で二重起動や再開漏れを起こさない。
- 停止中は再生フックを待ち、禁止対象なしの計測中はタグ更新を確認する最小限の処理だけを残す。Chrome拡張の既存自動再接続は維持し、補助を起動しない正常な待機と接続失敗を画面上で区別する。
- AFK検知と時間修正はまず本体の既存機能を利用・検証する。独自AFK検知は今回追加しない。

## サイト

- ドメイン単位で遮断する。登録ドメインとそのサブドメインを対象とし、文字列が似た別ドメインは対象外。
- 有効な許可サイトは、禁止サイトより優先して遮断対象から除外する。例：youtube.comを禁止し、music.youtube.comを許可すると、YouTube本体は遮断しMusicは利用できる。許可ドメインとそのサブドメインを対象とし、似た別ドメインは許可しない。
- 複数タグでは禁止サイトと有効な許可サイトをそれぞれ合算し、別タグによる禁止にも許可を優先する（2026-11-05ユーザー決定）。現在のタスクにないタグやオフのタグの許可設定は適用しない。
- 許可のオン・オフ／編集は計測中にも反映する。新規ページへの移動と既存タブへの切替で同じ判定を使い、許可を追加した既存の遮断タブは復帰、許可を外した既存の禁止サイトタブは遮断する。停止・休憩・期限切れでは禁止も許可例外も解除する。アプリの遮断には影響させない。
- Chrome自体や未登録のサイトは使える。新規移動だけでなく、作業前から開いていた禁止サイトのタブへの切替にも対応する。
- Chromeで検証する。同じ拡張コードをEdge・Brave・Vivaldi等のChromium系で利用できる設計とし、導入と検証はブラウザごとに行う。拡張がない・無効なブラウザを保護中と表示しない。

## Windowsアプリ

- **2026-11-04のユーザー決定により、アプリ機能は保存猶予なしの強制終了による遮断のみ。** 警告・通知・猶予・再警告は提供しない。
- アプリは実行ファイル名で照合し、複数タグの重複を除く。未登録アプリは対象にしない。
- 遮断は画面の有無に依存せず、登録した実行ファイル名のプロセスに適用する。起動済み・新規起動を区別せず、保存猶予・はい／いいえ・再確認・通常終了要求は提供しない。最小化方式やWindowsの実行制御設定変更は採用せず、起動前の実行拒否は保証しない。
- 未登録の子プロセスまでまとめて強制終了しない。補助自身、本体、Windowsの操作に必要な対象は登録できない。終了できない場合はエラー、終了処理中は待機状態として示し、遮断成功と偽らない。
- 旧設定の「警告のみ」登録は遮断へ自動変換せず、対象から外して案内する。既存の遮断・サイト設定を保持し、保存時に警告設定を含まない形式へ移行する。

## UIと言語

- 日本語・英語・繁体中国語に対応する。本体内はSuper Productivityの言語、Chrome拡張はChromeの表示言語へ自動で合わせる。独自の言語選択欄は追加せず、未対応の言語と欠けた翻訳は英語へフォールバックする（2026-11-05ユーザー決定）。
- 名称は日本語「タスク連動ブロッカー」、英語「Task-linked Blocker」、繁体中国語「工作連動封鎖工具」とする。アイコンは白黒・フラットな禁止マーク。本体とChrome拡張の表示名・製品アイコンを揃え、設定・接続のための内部IDは変えない。
- 見出し・項目名・メニュー・アクセシブル名・状態・入力／保存／接続エラー・拡張のポップアップと遮断画面を翻訳対象とする。ユーザー自身のタスク名・タグ名・アプリ名・ドメインや保存済みルールは翻訳・変更しない。
- 翻訳は言語別ファイルで管理し、キーと置換パラメーターの一致を確認する。動的な数値・一覧は言語に応じて整形する。表示中の本体言語変更でフォームを作り直さず、未確定入力・エラーを保持する。左メニューの製品名も本体の再読み込みなしで追従し、本体側の再描画で古い名前に戻らない。ほかのメニューは変更しない。本体上部ボタンの初期登録ツールチップは本体の再読み込みで反映できるようにする。
- 英語の長い項目や繁体字でも文字・操作部品が重ならず、狭い幅で必要に応じて折り返す。明暗テーマ、既存の寸法と操作、HTMLの100000バイト上限を維持する。翻訳のための新しい常駐処理・定期タイマー・権限・外部通信は追加しない。
- 設定画面最上部の製品名は控えめな見出しとする。20px・太さ500、アイコン20px、左端から8px内側を基準とし、各タグの操作より主張させない。左メニューでも禁止マークの内側を塗りつぶさず、線の形を保つ。左メニューのアイコンは18pxとし、文字の開始位置を本体の「今日」「受信トレイ」に揃える。名前を短縮して位置を調整しない。

- **本体と同じ感覚で使える外観にする。** 本体の実際のパーツのHTML構造・CSS・アイコンを可能な限りそのまま外観として転用し、推測で似せた独自装飾を完成形としない。パーツの機能・本体サービスまで持ち込まず、操作は集中ガードの既存コードへ接続する。
- 長い説明文・注意書きで操作を理解させる構成にせず、短いラベルと視覚的な操作を優先する。通常時の注意書きや自動保存・保存済み等の案内は表示せず、必要なエラーは簡潔に示し、既存機能・明暗テーマ・狭い幅での操作を維持する。
- プラグイン内の背景はテーマに合う単色とし、グラデーションを表示しない。本体全体のテーマ設定は変更しない。
- Chrome拡張の専用遮断画面には「タスク進行中」／「Task in progress」／「工作進行中」の短い見出しだけを表示し、説明文や操作案内は置かない。繁体中国語の製品内の案内でも「工作」を使う。
- Chrome拡張のポップアップは280×88pxの横長の枠で、接続状態の上に小さく薄めの製品名と16pxの禁止マークを置く。接続確認中・接続中・未接続・接続エラーを3言語で表示し、ドメイン一覧・説明文は置かない。Chromeの自動サイズ調整で狭くならないようルート要素の幅を明示する。接続表示は実際のソケット状態から判定し、遮断の成功状態とは区別する。未接続時はツールバーに「！」等のバッジを出さない。遮断件数と実際の遮断エラーの既存バッジは維持する。
- UI改善では、現在のローカル保存・入力検証・タグ判定・遮断・通信を維持する。保存先はローカルのままとする。
- 本体の既存タグを選ぶ方式で、禁止対象の追加・変更・削除を簡単に行える。
- 有効なタグ・ルール、プラグイン・補助機能・各接続ブラウザの状態、実際の適用可否を確認できる。
- アプリは実行ファイル名を追加するだけで遮断対象になる。対応方法の選択や警告関連の共通設定は表示しない。未実装機能を利用可能に見せない。
- タグごとの設定行・見出しで編集先が分かるようにする。対象件数は各「サイト」「アプリ」見出しの横に (1) のように数字だけを小かっこで表示し、タグ見出し右側の合計表示は置かない。追加・削除に連動して件数を更新し、空の入力行は件数に含めない。追加・削除は本体と同じアイコン等を使い、対象をアクセシブル名・ツールチップにも示す。空のアプリ行は保存対象から外す。保存ボタンは置かず、入力確定・項目削除・タグ変更等の有効な変更を自動保存する。入力途中・不正な内容で直前の有効な設定を上書きせず、入力エラー・保存失敗を分かるようにする。
- 設定画面の状態取得は表示中だけ行い、非表示・画面離脱では定期更新を止める。再表示時はすぐ最新状態を取得する。問い合わせを重ねず、表示の停止はタスク連動・遮断処理に影響させない。
- 状態は画面最下部に、小さめ・薄めの折りたたみ行として置く。見出し右側に「停止中」「未確認」等の状態値は並べず、計測・接続状態は展開した詳細で確認できるようにする。詳細表示・再接続・未保護やエラーの識別を維持する。
- 「タグを追加」は上の設定ボックスとの間隔を広げ、薄い外枠を持つボタンとする。サイト・アプリ名は上下の区切り線の中央に配置し、途中の行も同じ位置に揃える。すべてのサイト／アプリ見出しは14px、隣の＋アイコンは17pxとし、追加ボタンは基準位置から左へ1px移動する。
- タグ変更は見出しのタグ名の左に置くタグアイコンだけのボタンへ統合し、独立したタグ入力ボックスとタグ名の「#」は表示しない。ボタンは押せる外観にし、本体のメニューと同じチェック付きポップアップを開く。各ルールのタグは1つで、複数タグの禁止リスト合算は維持する。折りたたみ操作とは分離する。
- タグ見出しのゴミ箱の右にケバブメニューを置く。「許可サイトを追加」を本体由来のオン・オフUIで切り替える。オンのときだけ「サイト」の下・「アプリ」の上に「許可するサイト」欄を表示し、既存のリストと同じ追加・編集・削除・件数表示・入力検証・自動保存を使う。オフでは欄を隠して許可機能を無効にする。入力済みリストは保持し、再オンで復元する。
- ケバブメニューは同じボタンの再クリックでも閉じる。外側クリック・Escape・キーボードでの許可切替と、折りたたみとの分離を維持する。
- タグアイコンボタンの色は0.6.3より薄くする。サイトとアプリは縦並びのリスト形式とし、それぞれの見出し横の「＋」から項目を追加する。各行には項目名だけを並べ、チェックボックスやタグ表示は付けない。アプリの項目数にかかわらず、一覧下の余白を揃える。行のホバー時に右端へ削除ボタンを出す。キーボード操作でも削除ボタンを利用可能にする。設定行の寸法・区切り線は本体タスクリストの外観を流用する。
- リスト形式の外観は内蔵ブラウザーでの修正・確認を経てユーザー承認済み。本体版も同じ外観とし、自動保存を既存のローカル設定へ接続する。外観プレビューのサンプル設定は日常設定へ移行しない。
